# AI作为思维伙伴

<div class="part-intro">
本章内容提要：AI不只是生成器，也可以是思维陪练 / 让AI挑战你的观点 / 让AI找出论证漏洞 / 反例与不同立场 / 方案比较 / 决策矩阵与风险推演 / 最终判断权为什么必须留在人手里
</div>

::: info 情境案例
一位政治学系大三学生的选题是"数字政府建设对基层治理效能的影响"。她写好核心论点后，没有让Claude"帮我完善一下"，而是让Claude**尝试推翻她的论点**。

Claude指出了三个她完全没有考虑过的问题：基层公务员可能缺乏数据素养导致"数据存在但没人看"；线上化可能压缩基层灵活处置空间造成新型治理困境；基层数据采集中的造假和滞后问题使"垃圾进垃圾出"。

她把核心论点从单面论证修正为多面思辨。导师的评价："这才像一个做研究的人该有的思路。"
:::

## 生成器模式 vs. 陪练模式

| 维度 | 生成器模式 | 陪练模式 |
|------|----------|---------|
| **你的角色** | 指挥者 | 参与者 |
| **AI的角色** | 执行者 | 对手/搭档 |
| **对话价值在** | AI的输出里 | 你自己的头脑里 |
| **结束后** | 你多了一份成果物 | 你的思维变得更锋利 |

> 就像去健身房，舒服的训练不会让你变强，让你变强的训练一定不太舒服。

## 让AI挑战你的观点

核心方法：先陈述你的观点和理由，然后要求AI从反对立场出发尽全力反驳你。

**两个层次：**

1. **结论层面的反驳** - "你说A，但其实B"
2. **前提层面的质疑** - "你的论证依赖于一个你可能没有意识到的隐含假设，这个假设是否成立？"

> "在反驳我的结论之前，先检查一下我的论证是否依赖了某些我没有明确说出来的隐含假设。如果有，请指出来，并分析这些假设是否成立。"

::: warning 注意
不要把AI的反驳当作你必须全盘接受的"正确答案"。你的任务不是被AI说服，而是认真考虑每条反驳是否成立。关键是，你在审视反驳的过程中被迫进行了更深层次的思考。
:::

## 让AI找出论证漏洞

四种常见论证漏洞：

| 类型 | 特征 | 示例 |
|------|------|------|
| **因果跳跃** | 把相关性当因果性 | "社交媒体时间越长焦虑越高，所以社交媒体导致焦虑" |
| **以偏概全** | 用个别案例支撑普遍结论 | "两所重点中学试点成功，说明AI教学对所有学校有效" |
| **稻草人谬误** | 歪曲对方立场后攻击 | 把"传统媒体功能正在被替代"简化为"传统媒体没有价值" |
| **滑坡谬误** | 缺乏论证地从合理起点跳到极端结论 | "允许用AI做作业 -> 不自己思考 -> 教育体系崩溃" |

请求模板：

> "请你作为一位严格的逻辑学审查者，逐段检查我的推理过程。重点关注：因果关系是否成立？是否存在以偏概全？有没有稻草人谬误或滑坡推理？对于每个漏洞，请同时给出两种修补方案：一种是增加证据，一种是调整结论强度。"

## 反例与不同立场

**反例**划定你判断的有效边界，**不同立场**打破你对单一视角的依赖。

让AI生成反例：
> "我认为产业集群显著降低交易成本。有没有产业集群政策失败的案例？集群效应在什么条件下不起作用？"

让AI切换学科视角：
> "请分别从经济学、社会学和政治学的立场分析中国城市控烟政策的效果。"

指定学科身份比泛泛地说"从不同角度分析"更有效，因为它让AI切换了整套思维操作系统。

## 方案比较的三个层次

::: tip 有效方案比较
**第一层：优缺点并列** - 列出各方案的优缺点，但缺乏统一维度无法真正比较

**第二层：维度化对比** - 定义明确维度（成本、风险、可行性、时间等），逐维对比

**第三层：取舍意识** - 明确回答"如果选A，我在哪些维度上做了让步？这些让步我能否接受？"
:::
