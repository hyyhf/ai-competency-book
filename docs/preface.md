# 前言

大学校园里正在发生一场悄无声息的变化。

::: info 情境案例
2025年秋季学期，一位法学院的学生用ChatGPT检索劳动争议判例，写出了一篇结构严谨、论证流畅的课程论文。三周后，在模拟法庭上，对方逐条反驳她引用的案例，其中两个根本不存在，是AI凭空编造的。

同一年，一位商学院的同学用Claude分析了三家公司的年报，十分钟拿到一份图文并茂的竞品分析。导师翻了两页就放下了，评价只有四个字：**正确的废话**。

与此同时，另一位历史系学生把三十万字的清末外交档案喂给AI做初步梳理，再自己逐条核实、比对原始文献，发现了一个前人研究未曾注意到的条约细节，写出了一篇被导师称为"本科生少见的扎实之作"的学年论文。
:::

同样的技术，同样的模型，同样的校园。差别不在于谁更聪明，而在于谁知道如何**定义问题、准备材料、审查结果**，并为自己的判断负责。

这本书要讨论的，就是这道分水岭。

## 为什么写这本书

2026年4月，中国教育部等五部门联合印发了《"人工智能+教育"行动计划》，明确提出将人工智能全面纳入高校公共基础课体系。英国HEPI同年调查显示，95%的本科生已经在以某种方式使用AI，94%承认会用生成式AI辅助被评估的作业。

这些信号指向同一个判断：大学不能再假设"学生可能会用AI"，必须默认"**学生已经在用AI**"。问题不再是要不要用，而是怎么用才不会把自己变成一个只会复制粘贴的空壳。

市面上关于AI的书并不少。面向开发者的技术手册讲API调用和模型微调，面向管理者的趋势报告讲产业格局和商业模式。留给大学生的，大多是"如何使用ChatGPT"之类的工具操作指南，却很少触及一个根本问题：**在AI无处不在的世界里，你作为一个正在成长的年轻人，到底应该建立什么样的底层能力？**

## 关于本书

这不是一本教你"使用AI工具"的书。工具会迭代，界面会更新，今天的ChatGPT和半年后的ChatGPT可能面目全非。

这是一本教你在AI时代重新学习如何**学习、思考、判断、表达、组织信息和承担责任**的书。贯穿全书的核心逻辑是：

> AI时代真正稀缺的不是工具，而是使用工具的人所具备的底层能力。

本书把这些能力提炼为**七种素养**：认知、表达、学习、判断、信息、工具、责任。

## 全书结构

| 部分 | 核心素养 | 章节 |
|------|---------|------|
| 第一部分 重新认识AI | 认知素养 | 第1-2章 |
| 第二部分 学会提问 | 表达素养 | 第3-5章 |
| 第三部分 学会学习 | 学习素养 | 第6-7章 |
| 第四部分 学会判断 | 判断素养 | 第8-9章 |
| 第五部分 学会组织信息 | 信息素养 | 第10-11章 |
| 第六部分 学会使用工具 | 工具素养 | 第12-13章 |
| 第七部分 学会安全行动 | 责任素养 | 第14-15章 |

全书面向所有专业的大学生。你不需要有计算机科学背景，不需要会编程，不需要理解神经网络的数学原理。你只需要有好奇心、有耐心，以及一种对自己的学习和成长负责的意愿。
