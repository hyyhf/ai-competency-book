# 问题定义：比Prompt更重要的能力

<div class="part-intro">
本章内容提要：为什么模糊的请求注定得到平庸的回答 / 好问题来自清晰目标 / 六种任务类型 / 背景、对象、场景和限制 / 大问题的拆解 / 高质量AI请求的六要素
</div>

::: info 情境案例
一个正在写毕业论文的营销学研究生打开Claude，输入了一句话：帮我设计一份问卷。Claude给了她一份20道题的问卷，格式规范，看起来可以直接用。她确实直接用了。

两个月后，导师提出尖锐的问题：你的研究假设是环保意识影响购买决策，但问卷里只有两道题涉及环保态度。你没有区分环保动机类型，没有控制交互效应，也没有设计反向题。这份问卷和你的研究假设之间，存在严重的脱节。

教训不是"AI设计问卷不靠谱"，而是：**一个模糊的请求，注定只能得到一个泛泛的回答。**
:::

## 为什么"帮我写一下"不是一个好任务

"帮我写一下XX"是最自然、也最低效的AI使用方式。AI没有你和室友之间的共享上下文，面对信息真空，它只能用训练数据中最常见的模板来填补空白。

::: details 对比实验
**版本A**：帮我写一下关于《乡土中国》的读书报告。

你会得到一篇中规中矩、放在任何学生作业里都不会显得格格不入的文章。

**版本B**：我是社会学专业大二学生，正在上"中国社会结构专题"课。老师要求2000字，重点是选择书中一个核心概念，结合当代社会现象讨论。我打算选"差序格局"，结合社交媒体上的人际互动来分析。请帮我搭建论证框架。

第二种表述得到的回答会好出好几个层次。差异不在于Prompt技巧，而在于**任务定义的精度**。
:::

::: tip 定义：任务定义
任务定义是指将一个模糊的意图转化为一组清晰的、可执行的约束条件的过程。一个好的任务定义至少包含三个要素：**目标**（你要得到什么），**背景**（在什么条件下得到），**标准**（怎么判断得到的东西是好的）。
:::

## 六种任务类型

| 类型 | 你期望得到什么 | 你需要提供什么 |
|------|-------------|-------------|
| **答案** | 一个确定的事实或数据 | 精确度要求、时间范围 |
| **解释** | 对概念或现象的理解 | 你的知识水平、希望的深度 |
| **方案** | 一个可执行的行动计划 | 时间、资源等约束条件 |
| **比较** | 多选项的系统对比分析 | 比较维度、你的优先级 |
| **创意** | 新颖的想法和可能性 | 主题方向、受众、风格偏好 |
| **行动** | 一个直接可用的交付物 | 格式、规范、长度等精确要求 |

在向AI发出请求之前，花几秒钟想一想：我要的到底是哪种类型？

## 如何描述背景、对象、场景和限制

- **背景**（Background）：你为什么要做这件事？课程作业还是实习项目？
- **对象**（Audience）：谁会看到你的交付物？他们关心什么？
- **场景**（Context）：这个交付物会在什么情境下被使用？
- **限制**（Constraints）：字数、格式、理论框架、参考文献要求？

## 如何把大问题拆成小任务

以毕业论文为例，与其对AI说"帮我写毕业论文"，不如拆解为：

1. **文献检索与筛选** - 梳理相关研究，按方法分类
2. **研究设计咨询** - 让AI从方法论角度指出方案漏洞
3. **数据分析思路** - 确认统计方法选择是否恰当
4. **论文结构审查** - 审查逻辑结构和论证完整性
5. **语言润色** - 最终的措辞和语法优化

判断标准：如果一个子任务的输出你能在五分钟之内判断好坏，粒度就是合适的。

## 高质量AI请求的六要素

| 要素 | 核心问题 | 示例 |
|------|---------|------|
| **目标** | 我要得到什么？ | 一个2000字的案例分析框架 |
| **背景** | 我是谁，为什么需要？ | 法学大三学生，模拟法庭准备 |
| **材料** | 我能提供什么素材？ | 案件事实材料、相关法条 |
| **约束** | 有什么必须遵守的规则？ | 必须引用最高法指导案例 |
| **格式** | 输出应该长什么样？ | 分为事实、争议焦点、法律适用三部分 |
| **标准** | 什么算好的输出？ | 要有逻辑推导过程，不要罗列 |
